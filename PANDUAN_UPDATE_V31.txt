LANGKAH UPDATE GITHUB DESKTOP
1. Cadangkan folder aplikasi lama jika diperlukan.
2. Ekstrak K4_ConcreteLab_Pro_v3_1_UPDATE_GITHUB.zip.
3. Salin isi hasil ekstraksi ke dalam folder repo K4_ConcreteLab_Pro yang sudah dipakai.
   Struktur harus langsung app_pages/home.py, bukan folder bersarang tambahan.
4. Replace file tujuan yang sama. JANGAN hapus .git atau .venv.
5. Buka GitHub Desktop → Changes → pastikan home.py, CHANGELOG.md, dan file panduan terlihat.
6. Isi Summary: Refresh minimal elegant homepage v3.1
7. Commit to main → Push origin.
8. Periksa deployment Streamlit → buka BERANDA dan SERVICE di desktop dan HP.
