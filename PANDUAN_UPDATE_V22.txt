K4 CONCRETELAB PRO v2.2 - UPGRADE STATISTIK, GRAFIK INTERAKTIF, SIMULASI MUTU
================================================================================

PENTING: Ini UPDATE untuk proyek yang SUDAH dipasang v2.1.
Tidak perlu membuat repository GitHub atau deployment Streamlit baru.

1. Cadangkan folder K4_ConcreteLab_Pro lama bila diinginkan.
2. Ekstrak K4_ConcreteLab_Pro_v2_2_UPDATE_GITHUB.zip di folder sementara,
   contohnya Downloads/K4-v22-update (JANGAN langsung ke .venv).
3. Buka folder ekstraksi dan salin SELURUH ISINYA (app_pages, concretelab,
   tests, README.md, dll.) ke ROOT folder K4_ConcreteLab_Pro yang lama,
   sejajar dengan app.py, lalu pilih Replace saat diminta.
4. Jangan menghapus .git, .venv, app.py, atau file sumber lain.
5. Di GitHub Desktop, cek perubahan yang seharusnya mencakup:
   app_pages/service.py, concretelab/advanced.py, concretelab/reporting.py,
   tests/test_advanced.py, README.md, CHANGELOG.md.
6. Isi Summary: Upgrade statistik dan simulasi mutu v2.2
7. Klik Commit to main, lalu Push origin.
8. Periksa Streamlit Cloud: buka menu Service > unggah CSV > tes statistik,
   kurva simulasi target, ECDF, lalu unduh ZIP baru.
